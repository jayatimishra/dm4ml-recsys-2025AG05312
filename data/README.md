# data/

Generated by the pipeline and versioned with DVC (not stored in Git). Run `dvc repro` or
`python dags/run_pipeline.py` to create every folder below in about a minute.

| Folder | Layer | Written by | Contents |
|---|---|---|---|
| `sources/` | upstream systems (simulated) | `src/ingestion/generate_sources.py` | clickstream CSV, CRM users CSV, catalog JSON served by the mock REST API |
| `raw/` | landing / bronze, immutable | `src/ingestion/ingest.py` | `<source>/<entity>/ingest_date=YYYY-MM-DD/batch_<id>.*` + manifests + ingestion state |
| `validated/` | silver-1 | `src/validation/validate.py` | rows that passed all critical checks (Parquet) |
| `errors/` | error dataset | `src/validation/validate.py` | rejected rows with the ids of the failed checks (shipped in the ZIP as evidence) |
| `processed/clean/` | silver-2 | `src/preparation/prepare.py` | cleaned, typed users / products / interactions |
| `processed/splits/` | ML datasets | `src/transformation/transform.py` | time-based `train`, `valid`, `test` interaction files |
| `processed/derived/` | ML datasets | `src/transformation/transform.py` | user activity summary, item popularity, user-item matrix (CSR `.npz`) + index maps |
| `warehouse/` | gold | `src/transformation/transform.py` | SQLite star schema + point-in-time feature tables |
| `features/` | feature store | `src/features/feature_store.py` | `registry.db`, `offline/<view>/as_of=*.parquet`, `online.db` |

Trained models are written to `models/` by `src/training/train.py` and registered in MLflow.
